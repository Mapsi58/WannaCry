## WANNACRY, RANSOMWARE

**WannaCry** est un *ransomware* (rançongiciel) apparu en **mai 2017**, qui a infecté plus de
200 000 ordinateurs dans 150 pays en quelques jours seulement.

## DESCRIPTION

Il exploite une faille Windows nommée **EternalBlue**, développée à l'origine par la NSA
puis divulguée par le groupe *Shadow Brokers*. Une fois un ordinateur infecté, le ver se propage
automatiquement sur le réseau local sans aucune action de l'utilisateur, chiffre les fichiers,
puis affiche un message réclamant une rançon en **Bitcoin** pour les débloquer.

## IMPACT

1. Le **NHS** (système de santé britannique) a été gravement touché : opérations annulées
2. Des entreprises comme **Renault**, **FedEx** ou **Telefónica** ont été impactées
3. Les dégâts sont estimés à plusieurs **milliards de dollars**

> Un chercheur en sécurité, Marcus Hutchins, a stoppé la propagation en activant un *kill switch*
> caché dans le code, en enregistrant un nom de domaine précis.
